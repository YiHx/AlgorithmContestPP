# 算法竞赛++ 浏览器桥接（Chrome 扩展）

给 AtCoder / 洛谷 / 牛客 用的 Chrome 扩展（Manifest V3）：在**你已登录的页面上下文**里 fetch 平台数据，
转发给本机 `算法竞赛++ Engine`（`127.0.0.1:8765+`）。它不接管账号密码，也不发任何数据到外网。

> 为什么需要扩展：这三个平台没有可用的匿名公开接口（AtCoder 302 登录墙、洛谷 403、牛客无榜单），
> 详见 `research/platform-endpoints-v2.md`。

## 安装

1. 先启动引擎（在 `engine/` 目录）：

   ```powershell
   python ojhC.py run --url https://atcoder.jp/contests/abc300 --handle <你的用户名>
   ```

   引擎会打印 `浏览器桥接模式：http://127.0.0.1:8765` 并等待扩展。

2. Chrome 打开 `chrome://extensions` → 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择本目录（`extension/`）。
3. 保持比赛页面已登录并打开。扩展每 3 秒自动上报一次；点扩展图标可看连接状态。

## 各平台支持情况

| 平台 | 判题结果 | 实时榜单 | 说明 |
|---|---|---|---|
| AtCoder | ✅ 本人提交页 `/contests/<id>/submissions/me` | ✅ `standings/json`（登录后） | 封榜按场次声明；冻结标记取 `TaskResults[].Frozen` |
| 洛谷 | ⚠️ 暂未接入（v1 只上报榜单） | ⚠️ 成绩表分页找自己，名次按顺序推算 | 需要登录；OI 赛制比赛期间看不到评测结果 |
| 牛客 | ✅ `status-list`（中文 statusMessage） | ❌ 无榜单接口（研究确认 404） | 只有提交信号，压力分自动降级 |

## 已知限制

- 洛谷当前只上报榜单，缺少可用的本人比赛判题来源；
- 牛客没有榜单 → 压力分只用进度/停滞/提交趋势（设计里允许的降级档）；
- 所有平台都是**轮询**（3s 起，失败指数退避），不是推送；比赛高峰可能略慢；
- 页面结构/接口变动会导致解析失败：扩展会静默降级（不误报），需要更新 `content.js`；
- 牛客和 AtCoder 的本人判题在引擎启用设备输出后可触发设备。

## 安全说明

- 扩展只向 `127.0.0.1` 发请求，且必须携带引擎本次会话随机生成的 token；
- 引擎不读取你的 Cookie，扩展也不保存账号密码；
- 不要把 `extension/` 目录改成"允许外部访问"之类的实验设置。
